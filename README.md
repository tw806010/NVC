# 好好說｜非暴力溝通練習室

v1.0：以繁體中文提供非暴力溝通互動練習，支援手機與桌面。

## 功能

- 八張入門教學圖卡，包含兩組辨識練習。
- 六個生活情境，示例可自行修改。
- 觀察、感受、需要與請求引導，可複選及自訂詞彙。
- 表達草稿編輯、文字複製、PNG 圖卡下載。
- 不需登入，輸入僅存於頁面記憶體，重新整理即清除。

## 本機執行

需 Node.js 24。無需安裝套件。

```sh
npm run check
npm start
```

開啟 http://127.0.0.1:4187 。

## 發布

GitHub Pages 以 GitHub Actions 部署 main 分支。僅發布 index.html、style.css、app.js。

## 內容

概念參考：[玩轉學校｜非暴力溝通四步驟](https://pleyschool.org/blog/what-is-nvc/)。本專案重新編寫說明、題目及情境，未使用原文插圖。

工具提供日常溝通練習，不保證對話結果。Google Fonts 僅用於字型，載入失敗時使用系統字型。使用者輸入不會傳送至伺服器。
